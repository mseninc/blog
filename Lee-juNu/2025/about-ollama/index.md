## Ollama（オラマ） とは？

Ollama（オラマ）とは、ローカル環境で大規模言語モデル（LLM）を手軽に実行・管理できるオープンソースのツールです。インターネットに頼らずに使えるのが特徴です。

## なぜ Ollama を使っているのか？

1. LLM をローカルで実行可能なため、質問内容が学習される心配もありません。
2. いろんな LLM モデルをサポートしてくれてます。（llama3, gemma, deepseek r1, Mistral 等）
3. REST API を提供してくれます。

何より Ollama 選んだ理由は次の言葉ですね。

> Don't reinvent the wheel（タイヤを再発明するな）

llama.cpp から初めてモデルの準備、モデル設定準備などなどをする時間を使って次の開発ができるから Ollama を選びました。
