Docker を使っていると、さまざまなコマンドを駆使することが必要です。

特に、基本的なコマンドを押さえておくと、日々の開発や運用がスムーズになります。

そこで、個人的によく使用する Docker コマンドをまとめました。

本記事では下記の環境で動作確認を行っています。

- Docker version 
- Ubuntu Server 22.04.3 LTS

## よく使う Docker コマンド

### コンテナの一覧表示

現在実行中のコンテナを確認するには、次のコマンドを使います。

```bash:title=実行中のコンテナを表示
$ docker ps
```

全てのコンテナを表示したい場合は、`-a`オプションを追加します。

```bash:title=全コンテナを表示
$ docker ps -a
```

### コンテナの起動

新しいコンテナを起動するには、以下のコマンドを使用します。

ここでは、`ubuntu`イメージを基にしたコンテナを作成します。

```bash:title=コンテナを起動
$ docker run -it --rm ubuntu
```

### コンテナの停止

特定のコンテナを停止するには、`stop` コマンドを使用します。コンテナIDまたは名前を指定します。

```bash:title=コンテナを停止
$ docker stop <コンテナIDまたは名前>
```

### コンテナの削除

不要なコンテナを削除するには、`rm` コマンドを使用します。

```bash:title=コンテナを削除
$ docker rm <コンテナIDまたは名前>
```

実行中のコンテナを削除する場合は、`-f` オプションを追加して強制的に削除します。

```bash:title=実行中のコンテナを強制削除
$ docker rm -f <コンテナIDまたは名前>
```

### Dockerイメージの確認

ローカルに存在する Docker イメージを一覧表示するには、以下のコマンドを使用します。

```bash:title=イメージを表示
$ docker images
```

### イメージの削除

不要なイメージを削除する場合は、`rmi` コマンドを使用します。

```bash:title=イメージを削除
$ docker rmi <イメージIDまたは名前>
```
